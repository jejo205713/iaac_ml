# Data sources & attribution

The training data is a single file, **`dataset.jsonl`** (43,884 rows;
`split` ∈ {train, val, test}). Every row carries a **`source`** field recording
its provenance. The raw upstream corpora were removed from this repo to keep it
lean — but the *derived* command rows remain, so their licenses still apply.

> ⚠️ **Read before publishing or shipping commercially.** Several sources below
> carry **attribution (CC-BY)**, **share-alike**, or possibly **non-commercial**
> terms. Attribution sources *require* credit; non-commercial/share-alike terms
> can constrain a commercial product. **Verify each upstream license** for your
> use case — the labels below are best-effort, not legal advice.

## Not in this repo
- **Raw upstream corpora** (`datasets/`) — removed; re-clone from the projects above.
- **Trained weights** (`*.onnx`, `*.safetensors`) — rebuild via `run_all.sh` / `train_transformer.py`.
- **`_quarantine_realdata_unsafe.jsonl`** — quarantined real data, intentionally not published.

Command **strings only** — nothing in this repo executes.
